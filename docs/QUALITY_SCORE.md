# Quality score

The score is a release conversation, not a vanity percentage.

| Area | Baseline | Product Shell target |
|---|---|---|
| Architecture | Strong executor; coupled composition/bridge | Side Panel VM boundary and application contracts documented/tested |
| Domain separation | Strong local domains | No domain-to-UI/DOM leakage |
| UI consistency | Legacy developer overlay | Graphite/jade tokens across shell/HUD |
| Accessibility | Partial | Keyboard, focus, contrast, reduced preferences reviewed |
| Test quality | 374 passing unit/integration tests | Native shell, SBC, duplicate-route, local Router, Card protection, Pro contract, FC27 boundaries, recovery, commercial boundaries, and browser screenshot journeys |
| Recovery | Strong happy/applied-loss path | Broader fault matrix documented as debt |
| FC compatibility | FC26 implicit | Explicit FC27 unknown/unverified policy |
| Documentation | Useful but stale/no root map | Canonical linked sources + active plan |
| Data provenance | Good notices; single risky provider | Provider boundary and launch gate documented |

Known debt stays visible in the execution plans and reliability documentation.

Milestone 5 adds exact Pro schemas, descriptor-safe input validation,
request-local handle privacy, entitlement fail-to-Free matrices, proposal
revalidation, timeout/error sanitization, compatibility downgrade proofs and
package/permission boundary tests. A live service remains deliberately outside
the score because no endpoint or private backend exists.

Milestone 6 closes only its conditional no-backend path: the deterministic
optimizer and production service are specified in enough detail for a separate
team, while implementation, live performance, commercial authorization and
privacy approval remain explicitly unscored.

Milestone 7 adds a separate deterministic local Router domain, 12 pure-domain
tests, four runtime/presentation regressions, recursive identifier redaction,
Activity Guard/evidence fail-closed behavior, and normal/200%-zoom browser
screenshots. It deliberately scores no multi-step, Assisted or Auto routing;
those capabilities do not exist yet.

Milestone 8 adds an exact local game-strategy registry, separate bounded FC27
streamlined evidence and score-provider contracts, adapter-owned legacy version
compatibility, runtime version-switch invalidation, and a fresh pre-handler
execution gate. FC27 is intentionally scored as observe-only: no live rules,
score model, planning, submission, recovery, or compatibility claim exists.

Milestone 9 adds a pure deterministic Evolution graph planner, exact anonymous
PlayerState and verified-edge contracts, explicit OVR/role objective vectors,
Pareto alternatives, baseline separation, cycle/reuse defenses, and
fail-closed search/frontier bounds. It deliberately scores no live Evolution
coverage, price accuracy, activation, or consumer journey because the shipped
metadata provider is not configured.

Milestone 10 hardens the release boundary instead of scoring unavailable
commercial infrastructure. It adds fail-to-Free timestamp checks, an
uninjectable not-configured cloud provider, disabled external-data traffic,
legacy cache purging, minimized local support exports, exact legal links,
permission/CSP/package assertions, a split store/corresponding-source artifact
contract, provenance hashes, and a canonical commercial-readiness matrix.
Publication, payment, accounts, licensed providers, EA authorization, hosted
privacy/support operations, store media, and native release QA remain blocked
or not configured and therefore receive no readiness credit.
