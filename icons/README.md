# GrindPilot icon

`grindpilot-master.svg` is the original source artwork for the GrindPilot FC26
extension icon. It combines a navigation loop, a forward course marker and an
abstract letter G without using EA, FIFA, FC, FUT, club or player branding.

The four PNG files are purpose-rendered Chrome Manifest V3 assets. They were
exported from the SVG master with Inkscape at 16, 32, 48 and 128 pixels rather
than relying on browser-side scaling.

The artwork is part of GrindPilot FC26 and is distributed under the project's
GPL-3.0-only license.
